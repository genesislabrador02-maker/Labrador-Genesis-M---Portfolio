GENESIS M. LABRADOR — PORTFOLIO
================================

FILES
-----
index.html   = page content / text
style.css    = colors, typography, layout
script.js    = filters + project popup
images/      = profile and project images

EASY EDITING
------------
1. Replace images/project-01.jpg through project-08.jpg with your actual work.
2. Keep the same filenames and the website will update automatically.
3. Replace images/profile.jpg with your preferred portrait.
4. Edit text directly in index.html.

PREVIEW
-------
Double-click index.html and open it in Chrome/Edge/Safari.

ONLINE
------
The site is static HTML/CSS/JS, so it can be hosted for free on GitHub Pages,
Netlify, Vercel, or similar static hosting. Visitors only need a browser.
